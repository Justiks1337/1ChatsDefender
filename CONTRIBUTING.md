## Структура проекта

```
1ChatsDefender/
├── telegram/          # Реализация Telegram бота
│   ├── handlers/      # Обработчики сообщений
│   ├── chains/        # Цепочки обработки
│   └── middleware/    # Компоненты промежуточного слоя
├── utils/             # Вспомогательные функции и классы
├── ocr-service/       # Микросервис OCR (отдельная директория)
├── main.py            # Точка входа в приложение
└── requirements.txt   # Зависимости Python
```

## Настройка среды разработки

1. Установите Python 3.8+
2. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # В Windows: venv\Scripts\activate
   ```
3. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
4. Настройте переменные окружения в файле `.env` (смотрите `.env.example`)
5. Запустите приложение:
   ```bash
   python main.py
   ```

Для разработки с OCR сервисом также настройте микросервис OCR:
```bash
cd ocr-service
uvicorn src.main:app --host 0.0.0.0 --port 8000
```

## Стандарты кодирования

### Руководство по стилю Python

- Следуйте руководству по стилю PEP 8
- Используйте осмысленные имена переменных и функций
- Пишите docstrings для всех публичных функций и классов
- Делайте функции небольшими и сфокусированными
- Используйте аннотации типов, где это возможно

### Организация кода

- Разделяйте ответственность по разным модулям
- Используйте внедрение зависимостей, где это уместно
- Держите бизнес-логику отдельно от уровня представления
- Обрабатывайте ошибки корректно с соответствующим логированием

## Отправка изменений

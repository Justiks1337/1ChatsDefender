# Документация по агентам

В этом документе описаны ИИ-агенты, используемые в проекте 1ChatsDefender, и способы их настройки.

## Обзор

1ChatsDefender использует агенты opencode.ai для расширения своих возможностей, особенно для нейронной проверки сообщений в чатах Telegram. Агенты настраиваются через файл `opencode.json`.

## Конфигурация

Проект использует провайдер MWS с моделью Qwen Coder. Конфигурация находится в файле `opencode.json`:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "mws": {
      "npm": "@ai-sdk/openai-compatible",
      "name": "MWS",
      "options": {
        "baseURL": "https://gpt.mwsapis.ru/projects/project-dubkovmacsim/openai/v1"
      },
      "models": {
        "qwen3-coder-480b-a35b": {
          "name": "Qwen Coder"
        }
      }
    }
  }
}
```

## Языковые требования

Все агенты в проекте 1ChatsDefender должны общаться на русском языке, включая системные сообщения, ответы пользователю и логирование. Это требование распространяется на все компоненты системы, включая текущего агента opencode.

## Использование агентов

Агенты используются для нейронной проверки функциональности:

1. **NeuralCheckHandler** - Использует ИИ для анализа входящих сообщений на наличие неприемлемого контента
2. **AIClient** - Управляет подключением к сервису ИИ

Эти компоненты можно найти в:
- `telegram/handlers/NeuralCheckHandler.py`
- `utils/AIClient.py`

## Добавление новых агентов

Чтобы добавить новые агенты в проект:

1. Обновите файл конфигурации `opencode.json`
2. Создайте новые классы обработчиков в директории `telegram/handlers/`
3. Зарегистрируйте новые обработчики в `telegram/router.py`
4. Добавьте соответствующее промежуточное ПО при необходимости в `telegram/middleware/`

## Лучшие практики для агентов

1. Всегда обрабатывайте сбои API корректно
2. Реализуйте надлежащие таймауты для запросов ИИ
3. Кэшируйте ответы, когда это уместно, чтобы уменьшить использование API
4. Логгируйте взаимодействия с агентами для целей отладки
5. Убедитесь, что чувствительные данные не отправляются в сервисы ИИ
6. Все взаимодействия с пользователем должны быть на русском языке

## Команды разработки

Общие команды, используемые во время разработки с агентами:

```bash
# Запуск основного приложения
python main.py

# Запуск OCR сервиса (необходим для полной функциональности)
cd ocr-service && uvicorn src.main:app --host 0.0.0.0 --port 8000

# Запуск с Docker
docker-compose up
```

Примечание: Убедитесь, что OCR сервис запущен для полноценной работы агентов.
